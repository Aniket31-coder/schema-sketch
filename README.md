# Schema Sketch

Generate production-grade SQL DDL from [Mermaid](https://mermaid.js.org/syntax/entityRelationshipDiagram.html) ER diagrams. Three dialects: Oracle, PostgreSQL, MySQL.

**[Live →](https://schema-sketch.vercel.app)** · [Source](https://github.com/Aniket31-coder/schema-sketch) · [Portfolio](https://aniket-dewnani-portfolio.vercel.app)

---
## Local development

```bash
npm install
npm run dev    # http://localhost:3000
npm test       # run the test suite
```

## Stack

- Next.js 16 + TypeScript + Tailwind v4
- `prism-react-renderer` for SQL syntax highlighting
- Vitest for testing
- Fonts: Geist Sans, Geist Mono, Fraunces
- Deployed on Vercel
